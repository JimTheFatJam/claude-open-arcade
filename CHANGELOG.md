# Changelog

Each `## [x.y.z]` section becomes the release notes on GitHub and is shown in the in-app updater.

## [1.2.0]
- New: automatic updates. On launch (Wi-Fi only) the game checks GitHub for a new version and offers it on the home screen.
- Updates are downloaded in the background, verified (checksum and developer signature) and installed with Android's own installer.
- New UPDATES section in Settings: installed version, auto-check on Wi-Fi toggle and a CHECK FOR UPDATES button.

## [1.1.3]
- Redesigned chess pieces with clearer silhouettes and shading.
- The AWARDS button is now red so the trophy stands out.

## [1.1.2]
- Fixed a crash when continuing a game after changing its difficulty (2048, Lights Out, Flow Link, Nonogram).
- Saved games now resume at the difficulty they were played at.

## [1.1.1]
- Settings button on every screen, new restart icon, redesigned game icons and clearer button text.

## [1.1.0]
- Meowdoku rebuilt with real rules, interactive tutorial and tablet-friendly layouts across the app.
